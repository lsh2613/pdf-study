# 학습 자료

macOS/Linux에서는 다음으로 시작하세요.

```bash
./start_study.sh
```

Windows에서는 `start_study.bat`을 실행하세요.

두 스크립트는 이 자료를 렌더링한 프로젝트 환경을 사용하고, 사용 가능한 포트를 자동으로
선택해 브라우저를 엽니다. 따라서 이 자료를 생성한 컴퓨터에서만 실행해야 합니다.

문제가 있으면 다음처럼 직접 실행할 수 있습니다.

```bash
python study_html.py --port 8765
```

`--no-browser`를 더하면 브라우저 자동 열기를 끌 수 있습니다.

## 진도 저장

- `progress/_global.json` — 마지막 챕터/위치
- `progress/<chapter_id>.json` — 챕터별 읽음 진도, 답안, 객관식 정/오답 카운트

브라우저가 자동으로 저장합니다. 다른 기기로 옮길 때 `progress/`만 복사하면 됩니다.

## 문제 유형

- 객관식 (mc): 클릭 즉시 채점. `정답 X / 전체 Y` 형태로 표시 (점수 환산 없음).
- 단답형 (sa) / 주관식 (rf) / 확장형 (ex): 입력 후 "모범답안 보기" 버튼으로 자가 확인.
