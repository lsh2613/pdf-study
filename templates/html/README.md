# 학습 자료

```bash
python study_html.py
```

기본 포트 8765. 자동으로 브라우저가 열립니다. `--no-browser`로 끌 수 있습니다.

## 진도 저장

- `progress/_global.json` — 마지막 챕터/위치
- `progress/<chapter_id>.json` — 챕터별 읽음 진도, 답안, 객관식 정/오답 카운트

브라우저가 자동으로 저장합니다. 다른 기기로 옮길 때 `progress/`만 복사하면 됩니다.

## 문제 유형

- 객관식 (mc): 클릭 즉시 채점. `정답 X / 전체 Y` 형태로 표시 (점수 환산 없음).
- 단답형 (sa) / 주관식 (rf) / 확장형 (ex): 입력 후 "모범답안 보기" 버튼으로 자가 확인.
