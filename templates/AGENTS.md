# templates 기준

## 범위

이 디렉터리는 최종 결과물에 복사되는 파일을 담는다. HTML 템플릿 자산은 브라우저 학습 화면과 진도 저장 API를 지원하고, Markdown+TUI 템플릿은 터미널 학습 엔진과 챕터별 launcher를 제공한다.

렌더러가 데이터를 어떻게 읽을지는 `renderer/`의 책임이다. 템플릿은 이미 만들어진 결과 폴더 안에서 실행되는 코드와 정적 자산만 맡는다.

## 경계

템플릿 코드는 사용자의 결과 폴더를 기준으로 동작해야 한다. 저장소 루트나 개발 환경의 상대 경로에 의존하면 생성된 자료를 다른 위치로 옮겼을 때 깨진다.

`study_html.py`는 정적 파일과 progress API만 제공한다. 결과 폴더 밖 파일을 읽거나 쓰는 API를 추가하면 안 된다.

`study_tui.py`는 rich가 없어도 평문 모드로 실행되어야 한다. rich 설치 실패를 학습 자료 실행 실패로 승격하면 안 된다.

## 지켜야 할 동작

- 브라우저 진도 저장은 `progress/` 아래 JSON만 대상으로 한다.
- progress 이름은 안전한 챕터 ID나 global만 허용한다. 경로 구분자나 상위 경로 이동을 받으면 안 된다.
- HTML 자바스크립트는 완료 토글, 답안 복원, 객관식 채점 상태를 같은 progress 구조로 저장해야 한다.
- 챕터별 TUI launcher는 루트 엔진을 호출하는 얇은 파일이어야 한다. 챕터마다 엔진 복사본을 따로 유지하면 수정 누락이 생긴다.

## 테스트 기준

정적 서버, progress API, 안전하지 않은 이름 거부는 `tests/test_serve.py`를 확인한다. TUI 엔진의 rich 폴백과 챕터 실행은 `tests/test_md_tui_renderer.py`를 확인한다. 자바스크립트 진도 동작을 바꾸면 생성 HTML 안의 class와 data 속성도 함께 확인한다.
