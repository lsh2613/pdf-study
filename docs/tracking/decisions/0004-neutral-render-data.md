# 중립 JSON에서 출력 형식 생성

## 배경

같은 PDF 학습 자료를 브라우저로 보고 싶은 사용자와 터미널에서 보고 싶은 사용자가 모두 있다. 두 출력이 다른 저장 구조를 쓰면 내용과 진도 기능이 서로 어긋날 수 있다.

## 결정

챕터별 요약, 기본 문제, 확장 문제는 렌더러와 무관한 JSON으로 저장한다. HTML 렌더러와 Markdown+TUI 렌더러는 같은 저장 결과를 읽어 각자의 파일 구조만 만든다.

## 대안

- HTML을 먼저 만들고 TUI가 HTML을 파싱: 표시용 마크업이 데이터 계약이 되어 변경에 취약하다.
- 포맷별로 별도 생성 프롬프트 사용: 두 결과물의 요약과 문제가 달라질 수 있다.
- 한 출력 형식만 제공: 사용자 환경 선택 폭이 줄고, 브라우저 저장 서버와 터미널 학습 흐름 중 하나를 포기해야 한다.

## 결과

한 작업에서 출력 형식만 바꿔 다시 렌더링할 수 있다. 새 출력 형식을 추가하려면 중립 JSON을 읽는 렌더러를 추가해야 하며, 요약·문제 저장 스키마를 포맷 전용으로 갈라서는 안 된다.
