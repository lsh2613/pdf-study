# 확장 검색 실패는 작업 실패가 아님

## 배경

확장 문제는 책 내용과 연결되는 외부 맥락이 있으면 더 좋아질 수 있다. 그러나 외부 검색 서버, 네트워크, 검색 결과 품질은 PDF 학습 자료 생성의 핵심 경로보다 불안정하다.

## 결정

확장 문제 검색은 보조 기능으로 둔다. 검색 결과가 있으면 출처와 요약을 확장 문제에 활용한다. 검색 호출이 실패하거나 결과가 없으면 빈 결과를 돌려주고, 요약자는 본문 지식만으로 확장 문제를 만든다.

## 대안

- 검색 실패 시 챕터 실패 처리: 외부 의존성 문제로 전체 학습 자료 생성이 막힌다.
- 검색 기능 제거: 확장 문제의 현실 연결과 심화 맥락이 줄어든다.
- 검색 결과를 필수 근거로 취급: 검색 품질이 낮은 주제에서 잘못된 문제를 만들 수 있다.

## 결과

검색은 품질 향상 수단이지 완료 조건이 아니다. 서버는 검색 오류를 숨기지 않고 `exa_ok=false`와 오류 설명으로 남긴다. 확장 문제 저장은 검색 성공 여부가 아니라 `questions.extension`의 존재로 판단한다.
