# 확장 문제는 외부 검색 없이 생성

## 배경

확장 문제는 PDF 개념을 현실·실무 맥락과 연결하기 위한 문제다. 기존 구현은 외부
검색 결과와 출처를 보조 자료로 사용했지만, 확장 문제 자체는 챕터 본문과 학습자
정보만으로도 만들 수 있다. 검색 도구를 유지하면 네트워크 경계, 실패 처리, 결과
스키마와 렌더링 복잡도가 추가된다.

또한 단답형·주관식·확장형의 기존 기본 활성값은 사용자가 원하지 않은 문제를 만들 수
있다. 학습 목적과 배경지식을 받지 않으면 문제 난이도와 예시를 학습자에게 맞추기
어렵다.

## 결정

- 외부 검색 도구와 검색용 HTTP 클라이언트를 제거한다.
- 확장 문제는 같은 챕터 본문과 선택적으로 받은 학습자 정보만으로 만든다.
- 확장 문제 저장 항목은 `id`, `question`, `model_answer`만 사용한다.
- 객관식은 기존 호환을 위해 기본 활성으로 유지한다.
- 단답형·주관식·확장형은 기본값을 두지 않는다. `init_work`가 미정 선택지와 선택적
  학습자 정보 요청을 반환하고, `scan_pdf`가 사용자의 명시적 선택을 확정한 뒤
  스캔한다.
- 한번 확정한 문제 유형은 재스캔이 조용히 변경하지 못한다.

## 대안

- 검색을 선택 기능으로 유지: 외부 통신 동의와 검색 결과 스키마를 계속 관리해야
  한다.
- 확장 문제 자체를 제거: 현실·실무 적용을 연습하는 학습 가치를 잃는다.
- 모든 문제 유형을 계속 기본 활성화: 사용자의 필요와 무관한 생성 비용과 결과가
  생긴다.

## 결과

pdf-study 서버는 확장 문제 때문에 외부 네트워크를 호출하지 않는다. 사용자는 PDF를
스캔하기 전에 원하는 문제 유형을 직접 고르고, 원하면 학습 목적·배경지식·관심
분야·현재 수준을 제공한다. 프롬프트와 최종 출력에는 검색 결과 맥락과 출처 필드가
남지 않는다.
