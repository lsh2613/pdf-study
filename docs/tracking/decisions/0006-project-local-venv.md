# 저장소 로컬 실행 환경 사용

## 배경

MCP 클라이언트 설정에는 실행할 Python 경로가 들어간다. 전역 Python이나 다른 프로젝트 가상환경을 쓰면 사용자의 환경마다 의존성 차이가 생긴다.

## 결정

설치 스크립트는 저장소 안 `.venv`를 만들고, MCP 클라이언트 설정에는 `.venv/bin/python`의 절대 경로를 출력한다. 환경 검증은 이 Python에서 런타임 의존성과 `pdf_study` import를 확인한다.

## 대안

- 전역 Python 사용: 설정은 짧지만 의존성 충돌과 재현 실패 가능성이 크다.
- 사용자가 직접 venv 생성: 유연하지만 초보 사용자가 MCP 설정에 잘못된 경로를 넣기 쉽다.
- 패키지 배포 후 `pipx` 사용: 설치 경로가 단순해질 수 있지만 현재 로컬 개발·문서 흐름과 테스트 fixture 관리가 더 복잡해진다.

## 결과

설정 안내는 절대 경로를 그대로 복사하는 방식이어야 한다. 의존성 추가 시 설치 스크립트의 검증 모듈과 `pyproject.toml`을 함께 확인해야 한다. `.venv`는 커밋 대상이 아니다.
