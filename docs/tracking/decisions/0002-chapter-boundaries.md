# 챕터 경계 출처 제한

## 배경

PDF 학습 자료에서 챕터 범위가 틀리면 이후 요약과 문제도 모두 틀어진다. 스캔본과 글꼴 매핑이 깨진 PDF는 텍스트 추출 결과로 목차를 안정적으로 복원할 수 없다.

## 결정

챕터 경계는 PDF 내장 목차 또는 목차 페이지 이미지에서만 얻는다. 내장 목차가 있으면 그 PDF 페이지를 우선한다. 내장 목차가 없거나 틀렸으면 목차 페이지 이미지를 렌더하고, 클라이언트가 이미지를 읽어 챕터를 구성한다. 확정된 추출 범위는 `pdf_pages`, 원문에 표시된 페이지 번호는 선택적 `source_pages`로 구분한다.

## 대안

- PDF 텍스트에서 목차를 파싱: 디지털 PDF에서는 빠르지만 스캔본, 깨진 ToUnicode, 발췌본에서 페이지 번호와 줄 구조가 잘못 읽힐 수 있다.
- 무조건 균등 청크: 목차 해석이 필요 없어 단순하지만 책의 논리 구조를 잃는다.
- 사용자가 항상 직접 입력: 정확할 수 있지만 긴 책에서 작업 부담이 크다.

## 결과

챕터 범위 판단은 비용이 조금 들더라도 신뢰 가능한 출처를 우선한다. 텍스트 파서 기반 자동 목차 기능은 추가할 수 없다. 균등 청크는 목차를 읽을 수 없을 때의 보조 선택지로만 남는다.
