# pdf 모듈 기준

## 범위

이 모듈은 PDF 파일을 열고, 메타데이터·내장 목차·텍스트 품질·페이지 오프셋·페이지 이미지·본문 텍스트를 제공한다. MCP 도구 응답 형식, 작업 상태 저장, 요약 프롬프트, 최종 렌더링은 이 모듈의 책임이 아니다.

## 경계

페이지 번호는 공개 경계에서 항상 1부터 시작한다. PyMuPDF의 0부터 시작하는 인덱스는 `reader.py` 안에서만 사용한다. 다른 모듈에 0-based 번호를 넘기는 변경은 금지한다.

챕터 경계 자동화는 내장 목차와 렌더된 목차 페이지 이미지를 지원하는 수준에 머문다. 텍스트 추출 결과로 목차 항목과 페이지 번호를 파싱하는 기능을 이 모듈에 넣으면 안 된다.

## 지켜야 할 동작

- `get_outline`은 PDF 북마크의 물리 페이지를 그대로 돌려준다. 책 페이지 오프셋을 적용하면 안 된다.
- `extract_page_text`는 페이지 번호만 있는 줄과 과한 공백을 제거하되, 본문 의미를 바꾸는 교정을 하면 안 된다.
- `evaluate_text_quality`는 텍스트 유무와 모지바케를 구분해야 한다. 짧은 표본은 깨짐으로 단정하지 않는다.
- `render_pages`는 이미 렌더된 JPEG가 있으면 재사용한다. 같은 페이지를 반복 호출할 때 파일을 다시 쓰면 OCR 입력 캐시와 테스트가 흔들린다.
- `chapter.extract_chapter`는 주어진 물리 페이지 범위를 합칠 뿐 챕터 경계를 새로 판단하지 않는다.

## 테스트 기준

목차, 페이지 오프셋, 텍스트 품질, 이미지 렌더링을 바꾸면 `tests/test_pdf_reader.py`, `tests/test_recommendations.py`, `tests/test_analysis_e2e.py`를 확인한다. 페이지 번호 변경은 정상 범위와 범위 밖 오류를 함께 검증한다.
