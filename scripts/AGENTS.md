# scripts 기준

## 범위

이 디렉터리는 프로젝트 실행 환경을 준비하는 사용자용 스크립트를 담는다. 현재 핵심 스크립트는 MCP 실행용 로컬 `.venv`를 만들고 MCP 클라이언트 설정을 자동 적용하는 `setup_mcp.sh`다.

서버 기능 구현, PDF 처리, 렌더링, 테스트 fixture 생성은 이 디렉터리의 책임이 아니다.

## 경계

설치 스크립트는 저장소 위치를 스스로 계산해야 한다. 사용자의 현재 작업 디렉터리나 `~` 축약 경로를 MCP 설정에 넣으면 안 된다.

MCP 설정의 `command`는 `.venv/bin/python` 절대 경로여야 한다. `python`, `python3`, 상대 경로, 물결 경로를 등록하면 클라이언트가 다른 환경을 실행할 수 있다.

## 지켜야 할 동작

- `--print-config`는 설치를 실행하지 않고 현재 checkout 기준 JSON만 출력한다.
- `--check`는 이미 있는 `.venv`에서 필수 import를 확인하고, 없으면 실패해야 한다.
- 기본 실행은 기존 프로젝트 venv 재사용 또는 새 venv 생성, 패키지 재설치, import 검증, Claude Code/Codex CLI/Antigravity CLI의 전역 설정 자동 적용 순서로 진행한다.
- 대상 클라이언트를 지정하지 않으면 세 클라이언트 설정을 모두 적용한다.
- `uv`가 없으면 자동 설치를 시도할 수 있고, macOS에서 `libomp`가 없고 Homebrew가 있으면 설치를 시도할 수 있다.
- 새 런타임 의존성을 추가하면 import 검증 목록도 함께 갱신해야 한다.

## 테스트 기준

설치 스크립트 출력이나 검증 항목을 바꾸면 `tests/test_setup_mcp.py`를 확인한다. 실제 설치 명령을 바꾸는 경우에는 빈 환경에서 `./scripts/setup_mcp.sh --check`가 실패하고, 기본 실행 후 성공하는지 직접 확인한다.
